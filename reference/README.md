# Reference images

Mood references for look development. They are third-party images, so they stay local and are
git-ignored. Nothing in here ships with the site.

| File                                    | What to take from it                                                                                                                                                                       |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ref-01-dark-office-textured-wall.webp` | Low-key exposure that still holds shadow detail, warm grazing light on a heavily textured dark wall, wood ceiling, floor-to-ceiling window as the cool source, dark rug grounding the desk |
| `ref-02-dark-study-shelves.webp`        | Warm under-shelf strips as the main practicals, cool dark plaster, a single desk lamp pool, framed art catching just a rim of light                                                        |
| `ref-03-desk-led-strip.webp`            | One linear light source washing a plaster wall, everything else falling off to near black, small brass accents                                                                             |

All three read as CG interiors rather than photographs, so they set mood and lighting, not the
photographic realism bar in spec §4.6.
